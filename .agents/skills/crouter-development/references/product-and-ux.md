# 产品与交互契约

## 决策分层

**用户已确认：** 使用端仅 Claude Code；支持 API、订阅、多 Key、本地模型和 App 反代来源；自动化处理接入与切换；必须改善交互，不再让日常使用依赖冗长参数。

**本轮采用、可修改的默认值：** 同模型仅在用户启用的来源集合内自动切换；按量兜底和跨模型备用链默认关闭；按当前健康候选粘性选择，不逐请求随机轮换；中文交互优先，模型 ID 和协议字段不翻译；先支持现有 macOS/POSIX 路径，保留 Linux 离线兼容，不声称已支持 Windows。

**尚未决定，不阻塞前两阶段：** Antigravity 以外优先托管哪些 App 反代；各来源允许的账户导入/登录方式；是否需要更复杂的预算和均衡策略。先提供通用已有 endpoint 接入，不编造厂商能力。

## 入口和信息结构

TTY 下无参数 `crouter` 打开主页，回车默认使用上次有效选择进入 Claude Code；首次使用进入来源向导。主页只有用户任务：继续使用、选择模型、账号/订阅/Key、添加来源、自动切换设置、检查与修复。首页可显示当前模型、来源、计费规则和需要关注的状态，不显示密钥。

`crouter run` 等脚本路径保留非交互能力。无 TTY 不等待输入：已有有效选择按既有非交互契约运行，缺少必要输入则明确失败；不得消费本应传给 Claude 的 stdin。明确测试“有 stdout TTY 但 stdin 是管道”等组合。旧无参数行为的改变要有迁移说明，不能偷偷修改脚本语义。

默认不展示未配置的大目录。可以在添加来源页面查看可接入目录。不要把诊断页面充满用户没有打算配置的 provider 错误。

## 模型选择

- 模型优先，最近使用、收藏靠前；搜索名称、ID、来源别名，排序稳定。默认沿用该模型上次来源/策略，有需要才展开来源。
- 只有实际版本和能力等价且经过确认的模型才能合并来源。订阅路由别名、动态路由器、量化本地模型不自动与同名官方模型视为等价。
- 每行显示来源、计费类型和真实状态。区分“已配置”“已连通”“该模型已验证”；目录列出不等于账户有权限。
- 详情显示 context、支持的模态/工具、effort、主/辅助模型策略、数据来源和时间。输入/输出费率缺失时显示未知；免费筛选不能只判断输入价格为零。
- 选择→回车可使用；高级设置不阻断常用流程。不强制先建 Profile。用户显式启用辅助模型分工时保留映射，单模型模式才把各档绑定同一个模型。
- 返回/取消保留先前有效配置，不启动旧模型，不写半成品；选择结果用明确的 selected/cancelled/error 类型返回，不靠读取旧状态文件判断是否选择成功。

## 来源、账户与凭证向导

已有来源新增 Key、增加订阅账户、替换凭证、暂停/恢复、删除与重排优先级都在同一界面完成。

流程：选来源→接入方式→账户/订阅用途→无回显输入或受控导入→校验→保存。只有存在计费面歧义时询问一次；字段使用自然语言，不暴露 PLAN_KEYS 等实现变量。

批量粘贴：正确处理 bracketed paste、CRLF 和空行；默认一行一把 key，确需多行格式的凭证走适配器专用入口；先暂存、去重并给出不含原值的摘要，确认后一次提交。取消零持久化；部分写入失败回滚或明确逐项结果，不能显示“全部成功”。支持环境变量/密码管理器引用而不是强制复制秘密。秘密不进入终端历史、日志和命令参数。

账户与额度池分开：同一账户的多个 key 可能共享额度；无法确定时显示“共享关系未知”，不展示虚构的独立额度。查询接口没有返回余额时显示未知，不由成功次数推算百分比。

## 自动切换设置

四个独立控制项：同模型账户切换、允许的来源集合、是否允许按量兜底、备用模型链。来源集合变化涉及数据流向变化，新增来源不自动扩大旧会话的授权集合。

默认使用当前健康候选；订阅限流后在允许集合内切换，不反复弹窗。用去重、限频的状态消息说明真实来源变化和费用边界。锁定来源是硬约束，不因失败自动解除。

预算如实现必须区分本地估算与供应商账单；未知费率不能当零，不承诺精确硬预算。多个会话共用预算时需要原子预留，不把每个进程的局部计数当全局限额。

## 会话与错误恢复

主模型选择必须区分“用于新会话”和“切换指定活动会话”。已有活动会话按会话 ID 隔离；默认设置变更不广播。没有控制通道时不得声称在另一个终端保存配置就完成热切换。

Claude Code 内优先使用原生 `/model` 菜单；不要求日常切换手写长 ID 或另开终端。涉及启动级配置或不兼容历史时显示原因，提供继续当前模型、明确压缩/新会话或经验证的恢复流程；不静默截断历史。

错误应有就地操作：重新登录、更换凭证、稍后重试、查看脱敏详情、返回。离线时保留最近有效目录并标注过期；缺少 Node/CLI/Keychain 工具时解释缺失项，不进入无限加载。

## 终端交互质量

输入框内的 q 是普通字符；Esc 返回，Ctrl-C 明确取消。支持中文输入、多字节分片、粘贴、方向键、终端 resize、小终端滚动、无颜色模式。raw mode、光标、备用屏幕在异常和信号退出时也必须恢复。

长网络操作可取消且不会阻塞整个界面；首屏优先使用缓存，后台刷新属于当前进程可取消任务，不是常驻自动化。不得在页面绘制阶段解密全部 key、自动安装软件、运行 hooks 或发起推理。

## 可用性验收目标

有有效选择时主页回车即可启动；搜索已配置模型后回车即可使用；首次接入到启动不需要查 CLI 参数；取消在每一屏可用；故障恢复无需退出后手工编辑配置。通过伪终端脚本和一次真实终端走查验证，不只展示静态截图。
